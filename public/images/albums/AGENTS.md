# 相册媒体范围

同一目录下的 `README.md` 是完整的相册数据契约。这些本地说明指出了容易遗漏的操作约束：

- 每个 `public/images/albums/<id>/` 目录只保留一个 `info.json`。对于本地相册，请将 `cover.webp` 或 `cover.jpg` 排除在带编号的照片序列之外；当扫描顺序和稳定的公开 URL 很重要时，请使用零填充命名。
- 在受保护相册解锁过程中保留 `layout` 和 `columns` 的值。受保护相册使用与未受保护相册相同的画廊契约；密码只是一种静态浏览器门禁，并非服务端授权，且 `public/` 下已知文件仍可直接寻址。
- 不要在相册元数据中放置密钥或服务端授权的声明。远程媒体仍由其远程主机控制，示例媒体必须保留其现有的授权说明。
- 修改 `info.json` 或图片文件后，请从仓库根目录运行 `npx.cmd playwright test tests/site/albums.spec.ts`。在适用时检查生成的相册路由，以及受保护与未受保护两种变体。
