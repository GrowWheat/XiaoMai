admonitions在保持文章阅读流的同时，让支撑信息在视觉上有所区分。每种形式都在服务端渲染，并使用同一个紧凑的 M3E 组件。

## 语义变体

::: note 部署上下文
带空格的形式接受纯自定义标题，同时仍与引用语法兼容。
:::

:::info
将信息块用于帮助读者理解周围章节的中性上下文。
:::

:::tip[已有的 **label** 语法]
原始的方括号标签仍然可用，且可包含行内 Markdown 强调。
:::

> [!IMPORTANT]
> GitHub Alert 语法会进入同一个渲染器，因此已有文章保持统一的可视语言。

:::warning
运行生产构建前，请检查环境变量。
:::

:::caution
不要随示例一起发布凭据、本地配置或私钥。
:::

## 可选细节

::: details 检查完整命令
该折叠使用原生浏览器语义，无需客户端 JavaScript 即可保持键盘可达性。

```powershell
npx.cmd astro check
pnpm.cmd build
```

- 它初始为关闭状态。
- 长代码可在自身代码块内滚动。
- 在窄屏上，容器保持在文章宽度内。
:::

## 编写语法

```markdown
:::note[Existing title syntax]
Content
:::

::: warning Plume-compatible title syntax
Content
:::

> [!TIP]
> GitHub Alert syntax

::: details Optional content
Hidden until the reader opens it.
:::
```
