# 一级标题

段落之间用一个空行分隔。

第二段。_斜体_、**粗体** 和 `等宽字体`。无序列表
看起来像这样：

- 这个
- 那个
- 另一个

注意——先不论星号——真正的正文内容是从第 4 列开始的。

> 引用块是
> 这样写的。
>
> 它们可以跨多个段落，
> 只要你愿意。

用三个连字符表示破折号（em-dash）。用两个连字符表示范围（例如，“全部在
第 12--14 章”）。三个点 … 会被转换为省略号。支持 Unicode。☺

## 二级标题

下面是一个有序列表：

1. 第一项
2. 第二项
3. 第三项

再次注意，真正的正文是从第 4 列开始的（距左侧 4 个字符）。
这里是一个代码示例：

    # 让我重申一下……
    for i in 1 .. 10 { do-something(i) }

正如你可能猜到的，缩进 4 个空格即可。顺便说一句，如果不想
缩进代码块，你也可以使用围栏代码块：

```
define foobar() {
    print "Welcome to flavor country!";
}
```

（这样复制粘贴更方便）。你还可以可选地标记该围栏块，让 Pandoc 对其进行语法高亮：

```python
import time
# 快，数到十！
for i in range(10):
    #（但别太快）
    time.sleep(0.5)
    print i
```

### 三级标题

现在是一个嵌套列表：

1. 首先，准备这些食材：

    - 胡萝卜
    - 芹菜
    - 扁豆

2. 烧一些水。

3. 把一切都倒进锅里，然后
    按这个步骤来：

        find wooden spoon
        uncover pot
        stir
        cover pot
        balance wooden spoon precariously on pot handle
        wait 10 minutes
        goto first step (or shut off burner when done)

    别碰木勺，否则它会掉下来。

注意，文本始终对齐在 4 个空格的缩进处（包括
上面续写第 3 项的最后一行）。

这里有一个指向 [某个网站](http://foo.bar) 的链接，一个指向 [本地
文档](local-doc.html) 的链接，以及一个指向当前文档中
[某个小节标题](#an-h2-header) 的链接。这里还有一个脚注 [^1]。

[^1]: 脚注文字写在这里。
